# IrisShot

[简体中文](README.md) | [English](README_EN.md) | [Українська](README_UK.md)

IrisShot — це інструмент для створення довгих скриншотів, розроблений для альбомних (горизонтальних) ігор на Android. Він створює панорамні зображення за допомогою захоплення екрана, автоматичного скролінгу, аналізу зміщення кадрів та інтелектуального зшивання.

## Можливості

- Горизонтальні та вертикальні довгі скриншоти
- Гнучке налаштування областей: область захоплення, зона свайпу та фіксовані смуги інтерфейсу
- Два режими захоплення: через стандартний `MediaProjection` API або через `Shizuku`
- Експорт зображень у форматах JPG та PNG
- Попередній перегляд результату, кадрування, повторне зшивання та надсилання

## Системні вимоги

- Android 10 (API 29) або новіша версія
- Для автоматичного скролінгу потрібен дозвіл Спеціальних можливостей (Accessibility) або режим Shizuku

## Збирання проєкту

Відкрийте проєкт у Android Studio, виконайте синхронізацію Gradle та запустіть конфігурацію `app`.

- JDK 21
- Android SDK 36.1
- Gradle 9.4.1
