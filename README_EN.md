# IrisShot

[简体中文](README.md) | [English](README_EN.md)

IrisShot is a long screenshot tool designed for Android landscape games. It creates long screenshots through screen capture, automatic scrolling, image analysis, and image stitching.

## Features

- Horizontal and vertical scrolling screenshots
- Configurable capture, swipe, and fixed regions
- MediaProjection and Shizuku capture modes
- PNG, JPEG, and WEBP export
- Result preview, cropping, restitching, and sharing

## Requirements

- Android 10 (API 29) or later
- Automatic scrolling requires Accessibility permission or Shizuku mode

## Build

Open the project in Android Studio, sync Gradle, and build the `app` configuration.

- JDK 21
- Android SDK 36.1
- Gradle 9.4.1
